## ✨ Features

- 🎧 **Instant Player & Fast Streaming**: Zero-lag direct playback powered by ExoPlayer / Media3 with background playback, lock screen controls, and rich media notifications.
- 🔄 **Continuous Repeat All & Single Track Loops**: Smooth playlist looping that seamlessly returns to top (#1) on playlist completion or drag gesture.
- 🌍 **Region & Country Personalization**: Select your country (India 🇮🇳, United States 🇺🇸, UK 🇬🇧, Canada 🇨🇦, UAE 🇦🇪, etc.) with localized YouTube InnerTube charts.
- 🗣️ **Multi-Language Music Suggestions**: Choose multiple languages (Hindi, Punjabi, Bhojpuri, English, Haryanvi, Tamil, Telugu, etc.) with dynamically generated Home sections & mood chips.
- 📈 **Trending Songs in India**: Ranked #1, #2, #3 trending charts tailored to your selected region and language preferences.
- 📥 **Offline Downloads & 30-Day Smart Cache**: Save your favorite songs permanently for offline listening or auto-cache recently played tracks.
- 📼 **YouTube Playlist Importer**: Import your favorite YouTube / YouTube Music playlists with a single link or ID.
- 🎤 **Synchronized Real-time Lyrics**: Real-time LRCLIB timed lyrics with auto-scrolling line highlights.
- ⏱️ **Sleep Timer**: Fall asleep to your favorite music with customizable countdown timers.
- 🖤 **Futuristic Dark UI**: Modern OLED dark theme with lime & violet glassmorphism accents.

## 🛠️ Tech Stack & Architecture

- **Language**: 100% Kotlin
- **UI Framework**: Jetpack Compose, Material 3
- **Audio Engine**: AndroidX Media3 (ExoPlayer) + Foreground Service
- **Networking**: OkHttp 4, Kotlinx Serialization
- **Image Loading**: Coil 3
- **Architecture**: MVVM + Coroutines + StateFlow / SharedFlow

## 🚀 Building from Source

```bash
# Clone the repository
git clone https://github.com/kanXer/Riva-Music-by-Nexus-Digital.git
cd Riva-Music-by-Nexus-Digital

# Build Release APK
./gradlew assembleRelease

# The generated APK will be located at:
# app/build/outputs/apk/release/app-release.apk
```
